**Границы классов.** Числовая граница есть у количества цифр: 10 / 11 / 12. Для дискретных классов — префикс, разделители, тип кода — числовой границы нет; проверяются представитель класса и ближайший структурный вариант, отличающийся одним элементом от валидного значения.

## Задание 3.2. Таблица принятия решений

### Условия и действия

Таблица построена по буквальной формулировке задания 3.2 с тремя условиями:

- **N** — поле «Ваше имя» заполнено, то есть содержит непустое значение.
- **P** — поле «Номер телефона» заполнено.
- **V** — введённый телефон валиден по правилу телефона.

Действия:

- **A0 — отказать:** не создавать запись, не показывать «Запись подтверждена», показать ошибку незаполненного или невалидного поля.
- **A1 — подтвердить:** при прочих выполненных предусловиях создать запись и показать окно «Запись подтверждена».

Правило из формулировки: `Подтвердить = N AND P AND V`.

**Логическая зависимость:** `V = Да` невозможно при `P = Нет`, потому что пустой телефон не может быть валидным. Такие комбинации показаны в полной таблице как недостижимые, а не как отдельные проверяемые сценарии.

### Полная таблица комбинаций

| Правило | N: имя заполнено | P: телефон заполнен | V: телефон валиден | Достижимость | Ожидаемый результат системы |
|---|---|---|---|---|---|
| R1 | Нет | Нет | Нет | Достижимо | **A0 — отказать.** Ошибки: имя не заполнено, телефон не заполнен. Запись не создаётся. |
| R2 | Нет | Нет | Да | Недостижимо | Не применимо: пустой телефон не может быть валидным. |
| R3 | Нет | Да | Нет | Достижимо | **A0 — отказать.** Имя не заполнено; телефон невалиден. Показать применимые ошибки, запись не создавать. |
| R4 | Нет | Да | Да | Достижимо | **A0 — отказать.** Телефон корректен, но имя не заполнено. Запись не создаётся. |
| R5 | Да | Нет | Нет | Достижимо | **A0 — отказать.** Телефон не заполнен. Запись не создаётся. |
| R6 | Да | Нет | Да | Недостижимо | Не применимо: пустой телефон не может быть валидным. |
| R7 | Да | Да | Нет | Достижимо | **A0 — отказать.** Оба поля заполнены, но телефон невалиден. Запись не создаётся. |
| R8 | Да | Да | Да | Достижимо | **A1 — подтвердить.** Все три условия выполнены: создать запись и показать окно успеха, если остальные предусловия записи выполнены. |

Из 8 формальных комбинаций достижимы 6. Единственная достижимая комбинация, разрешающая подтверждение по заданному правилу, — **R8**.

### Согласование с требованием к имени 

```text
Подтвердить =
    ИмяЗаполнено
    AND ИмяВалидно
    AND ТелефонЗаполнен
    AND ТелефонВалиден
```

Тогда строка R8 разделяется на две проверки:

| Имя заполнено | Имя валидно по 3.1 | Телефон заполнен | Телефон валиден | Результат |
|---|---|---|---|---|
| Да | Нет, например `12` или `Анна Петрова` | Да | Да | Отказать: ошибка имени, запись не создаётся. |
| Да | Да, например `Анна` | Да | Да | Подтвердить при прочих выполненных предусловиях. |
